# 大明 · 故人长卷

当前版本：1.1.0。

公开源码：[LinYangBIT/ming-chronicle](https://github.com/LinYangBIT/ming-chronicle)。

国风绘本风格的中文历史网页游戏。了解十二位明朝人物，从其中十一位可同行人物中按章节结缘，在六幕历史选段里作出抉择、经营资源、指挥三路战役，最后生成可以分享的人生签。

人物取自《明朝那些事儿》所涉及的真实历史人物；对白、分支、卡通形象与规则是本项目的原创演绎。六幕不是现代原著的全本移植，也不宣称官方改编。

## 本地运行

需要 Python 3；使用 npm 命令和运行逻辑测试还需要 Node.js。无须下载运行依赖、配置账号或填写密钥。

```sh
npm start
```

浏览器打开 <http://127.0.0.1:4196>。也可以直接运行：

```sh
python3 -m http.server 4196 --directory dist
```

请通过 HTTP 服务打开，避免直接双击 `index.html` 引起 ES module 加载限制。`dist/` 同时包含可编辑源码与静态资源，没有另一个隐藏的构建源目录；Phaser 3.90.0 已保存在 `dist/vendor/`，游戏主体不依赖 CDN。

## 玩法与操作

- 点击或触摸「入卷，写我的人生」，依次经历六幕；桌面键盘可以用 Tab 聚焦按钮、Enter 激活。
- 每幕选择一位同行人物，获得属性助益；完成三次剧情抉择，积累仁心、谋略或胆识。
- 在民心、粮草、军备、声望之间取舍。每幕最多进行两次经营，也可以跳过筹备进入战役。新行囊可选择持衡阵、锋矢阵、坚壁阵，分别偏向均衡、进攻或防守。
- 战役先选择左、中、右路，再选择战术。坚守克制突进，迂回克制固守，齐射克制伏击但消耗粮草；强攻无需额外粮草。观察斥候情报，在八回合内击破对手。
- 六种地形有不同效果：湖战火船、城巷迂回、海上顺风、城墙修复、海防协同、改革预算。具体规则在当幕战役中显示。
- 十一位可同行人物各有专属战技：新行囊中，两次战术行动蓄满两点，每场仅能施展一次。只可使用当章允许选择的同行人物，并非任意人物跨时代上阵；朱允炆是史册人物，本卷不可同行。
- 每幕有一个与地形相关的额外目标，达成可增加人生回响；例如湖战两次齐射、海战两次借顺风出击。
- 点击「暂停」或 Esc 暂停画面和配乐；点击「存卷」返回首页，之后可续写长卷。战役是回合制，未下达行动时不会自行推进。
- 战役结算后，无论胜负均可「重试本幕」，恢复进入战役前的检查点，再进行该场战斗；也可带着当前结果继续故事。旧版已经处于战役中的存档没有追溯生成的检查点。
- 结算可保存 900×1200 PNG 人生签、复制战报及同题链接，或点击「再走一种人生」重开。未完成时另起一卷会先提示替换当前进度。
- 顶栏音乐按钮打开独立的背景音乐、音效开关和音量设置。偏好会保存在当前浏览器。

| 键盘 | 操作 |
| --- | --- |
| `1` / `2` / `3` | 选择左 / 中 / 右路 |
| `Q` / `W` / `E` / `R` | 强攻 / 坚守 / 迂回 / 齐射 |
| `F` | 施展已蓄满的同行能力 |
| `Esc` | 暂停；弹窗打开时关闭弹窗或恢复 |

触屏通过同名按钮完成全部操作。快捷键只在合适的战役阶段生效，输入框操作不会触发战术。

「今日同题」使用北京时间的日期种子，并确定一种局势：劲敌临阵、粮道紧张或东风相助。链接中的同题种子让朋友遇到相同初始随机条件；任意非每日日期种子不附加每日局势。不同决策仍会产生不同结果，这不是联机对战或全服排行。

## 背景音乐

原创程序合成配乐采用 32 小节循环编排，菜单、行旅、战役和结局有四种场景主题与节奏。无保存偏好时，背景音乐和音效均默认开启、音量非零；页面尝试启动，若浏览器限制自动播放，会在第一次有效点击、触摸或按键时自动解锁，不需要再点击开启按钮。

暂停游戏、切到后台时配乐暂停，恢复后重新安排音符，不补播积压片段。玩家静音、音量和音效偏好相互独立并在刷新后保留；不支持 Web Audio 的浏览器仍可无声游玩。

## 内容与存档

现有内容包括 12 位史册人物（其中 11 位可同行）、6 幕、18 个事件、54 个选择、6 种人生签，以及故人图鉴与最近 20 份人生记录。每幕的「史实回望」独立于玩家演绎，不随战斗结果改写。

存档只写入当前浏览器的 `localStorage`，沿用 v1 行囊与人物记录键。1.1.0 新建行囊使用规则集 2；有效旧 v1 行囊继续旧战斗、随机与结局规则，不强行升级为新规则。无效记录会经过结构校验并被忽略。浏览器禁止存储时会提示进度只能在当前页面保留。清除网站数据、更换浏览器或更换网址不会同步原来的存档；本作没有账号云存档。

分享图片不需要游戏服务器。挑战链接使用当前游戏网址，接收者需要有权访问该网址；本地 `localhost` 地址不能作为朋友的远程游戏入口。GitHub 源码公开与 Sites 站点权限互相独立：所有者私有的 Sites 入口仍需要访问权限，不会因代码开源而自动对外开放。

## 源码结构

| 路径 | 用途 |

## 验证

```sh
npm test
```

规则检查覆盖六幕完成、确定性重放、旧 v1 存档、三种阵形、同行能力、额外目标、每日局势、资源边界、重复行动、回合上限与结局。音频合约检查覆盖默认开启、首次操作解锁、32 小节以上连续排程、场景切换、独立偏好、暂停、后台、页面恢复与清理。

这些测试不是实际听感或手机实机证据；浏览器画面、触屏、声音和下载仍需实际浏览器操作确认。公开导出不携带个人 QA 存档、截图或浏览器日志。

## 史料与素材

本仓库不含《明朝那些事儿》现代原著全文。游戏内「史料馆」提供正版阅读入口与古籍出处。

开发研究使用了《明史》13 卷，出处见 [史料说明](research/history-sources.md)。公开导出只保留说明与可选下载脚本，不携带抓取的 HTML、TXT 或本地校验清单。需要自行研究时可运行：

```sh
python3 research/download-sources.py
```

该操作会联网读取维基文库，在 `research/sources/` 生成资料与来源清单；不影响游戏运行，也不下载现代原著。

候选仓库与版本依据见 [仓库研究](research/repository-research.md)，主视觉生成记录见 [美术说明](research/art-direction.md)。
